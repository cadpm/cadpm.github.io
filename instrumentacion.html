Conectar la medición física con el sistema de datos

La instrumentación industrial requiere instalación, configuración, comunicaciones y diagnóstico. Mi trabajo en esta área reúne intervenciones en terreno y desarrollo de software para adquirir e integrar mediciones.

Mi aporte

Instalé y configuré radares, sensores de nivel y flujómetros ultrasónicos. También integré sistemas de pesaje y desarrollé comunicaciones para incorporar información de equipos y PLC a los sistemas de monitoreo.

Cómo lo resolví

  • Realicé canalización, cableado, montaje de sensores y gabinetes, instalación de tubería EMT y puesta en marcha.
  • Desarrollé adquisición de mediciones de radares mediante comunicaciones Modbus y enlaces serie/Ethernet.
  • Implementé validación de respuestas, filtrado de mediciones, gestión de tiempos de espera y recuperación de conexiones.
  • Preparé herramientas de configuración y diagnóstico para revisar sensores y parámetros de comunicación.
  • Integré datos de pesaje mediante adquisición serie y consultas a SQL Server.
  • Conecté sistemas de adquisición con PLC Allen-Bradley, Omron y Siemens para obtener datos de planta.

Recorrido de la información

Sensor o equipo → Interfaz de comunicación → Lectura y validación → Procesamiento → Sistema de monitoreo.

Resultado del trabajo

Combiné montaje en terreno, integración de equipos y programación para incorporar mediciones físicas a los sistemas de datos. Desarrollé herramientas para revisar comunicaciones y diagnosticar problemas durante la instalación y el soporte.

Tecnologías: Radares de nivel, flujómetros ultrasónicos, balanzas dinámicas, Modbus, RS-485, Ethernet, Python, SQL Server y PLC industriales.
