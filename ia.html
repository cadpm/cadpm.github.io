PROYECTO 04 / IA para producción

Investigar el tiempo perdido.

Un agente que combina registros de fallas, cálculos y documentación técnica para proponer mejoras.

PreguntaDatos + cálculoDocumentaciónRespuesta

PREGUNTAS, HERRAMIENTAS Y RESPUESTAS REALES

El agente en acción.

Consultas ejecutadas con el cliente Python del proyecto y procesadas por LangGraph en Docker. Los análisis utilizan un CSV ficticio; la consulta teórica recupera documentos de la biblioteca. Las capturas muestran una vista de esas salidas preparada para el portafolio.

Convertir registros de fallas en preguntas que se puedan investigar

Los registros de fallas y paradas permiten estudiar las pérdidas de producción. Para interpretar esos datos también resulta útil consultar documentación técnica y relacionar los hallazgos con posibles acciones de mejora.

Mi aporte

Desarrollé un agente de IA que combina herramientas de análisis de datos con recuperación de documentación. Este proyecto forma parte de mi experiencia reciente en aplicaciones con modelos de lenguaje para problemas industriales.

Cómo lo resolví

  • Organicé el flujo del agente y sus herramientas con LangChain y LangGraph.
  • Implementé cálculos en pandas para consultar registros, comparar períodos y analizar tendencias.
  • Integré una biblioteca de documentos técnicos con Neo4j para recuperar información y referencias.
  • Incorporé modelos locales mediante llama.cpp.
  • Expuse funciones mediante FastAPI y organicé los servicios con Docker.
  • Incorporé fuentes documentales a las respuestas para fundamentar las recomendaciones.

Preguntas que orientan el caso de uso

  • ¿Dónde se concentra el tiempo perdido durante un período?
  • ¿Qué fallas se repiten y cómo cambian entre períodos?
  • ¿Qué documentación puede ayudar a investigar una causa?
  • ¿Qué acciones de mejora se pueden proponer a partir del análisis?

Recorrido de la información

Pregunta → Consulta de registros y cálculos → Recuperación de documentación → Análisis del agente → Respuesta con recomendaciones y fuentes.

Resultado del desarrollo

Construí un agente que reúne consultas, cálculos y documentación técnica en un mismo flujo de análisis. El proyecto amplía mi trabajo en adquisición e integración de datos hacia su interpretación mediante IA.

Tecnologías: Python, LangChain, LangGraph, pandas, Neo4j, llama.cpp, FastAPI y Docker.
