¿Qué es el OEE y cuáles son sus componentes?

RESPUESTA DEL AGENTE

El OEE, o Eficiencia Global del Equipo (Desempeño Operacional), es un indicador que integra la disponibilidad, el rendimiento y la calidad para medir la eficiencia real de un equipo o línea de producción [2], [3]. Su objetivo es identificar las pérdidas productivas reales para enfocar las acciones de mejora [3].

El OEE se calcula mediante la multiplicación de sus tres componentes principales:

  1. % Disponibilidad: Mide las pérdidas causadas por detenciones no programadas [1].
  2. % Rendimiento: Mide las pérdidas causadas por la velocidad o la operación a una velocidad inferior a la ideal [1], [3].
  3. % Calidad: Mide las pérdidas causadas por defectos o mermas [1], [3].

La fórmula general es OEE = % Disponibilidad x % Rendimiento x % Calidad [1], [3], [4].

Para calcular la disponibilidad, se utiliza el Tiempo de Carga, que se define como: Tiempo de Carga = Tiempo de Turno - Tiempo de Paradas Programadas - Tiempo Sin Producción [1].
